## 🧠 Engineering Principles

> Clean code is not about writing less code.
> It is about writing code that is easier to understand, change and maintain.

```text
Readable
   ↓
Testable
   ↓
Maintainable
   ↓
Scalable
```

I care about:

* Clean architecture
* SOLID principles
* Strong typing
* Small focused classes
* Clear naming
* Proper return types
* Automated testing
* Refactoring
* Maintainable codebases
